# AUDIT 2026-10-04 — R8, ukuran install, fullscreen, UI liquid glass

Mode: **AUDIT -> IMPLEMENT** untuk permintaan: ukuran install melonjak, tambah R8, UI/UX kurang konsisten/terlalu bulat, liquid glass untuk background/dock, pastikan fullscreen.
Commit dasar saat audit: `bcf4aac` (`main`, setelah draft `v0.4.1-alpha`).

## Temuan cepat

1. **R8 sebenarnya sudah aktif untuk release** (`isMinifyEnabled=true`, `isShrinkResources=true`), dan APK draft `v0.4.1-alpha` hanya 2.283.840 byte. Jadi angka install 200 MB kemungkinan berasal dari salah satu ini:
   - build debug yang tidak di-minify;
   - cache/data/compiled oat ART yang dihitung Android sebagai ukuran aplikasi;
   - laporan ukuran dari Settings yang menjumlah APK + data + cache.
2. Debug build sebelumnya tidak memakai R8. Bila APK debug dipasang manual, ukuran dan dependency Compose bisa terasa membengkak.
3. `proguard-rules.pro` masih menyimpan `SourceFile/LineNumberTable`; ini berguna untuk stacktrace, tetapi tidak wajib untuk APK uji dan menambah metadata dex.
4. UI memakai radius 8/12/16/14 dp dan icon mask 26% ukuran; di layar kecil terasa terlalu bulat/toy-like.
5. `Glass()` masih berupa permukaan gelap semi-opaque + sheen tipis. Belum terasa liquid glass karena pengaruh wallpaper/background kurang terlihat.
6. Fullscreen sudah lewat `WindowInsetsControllerCompat`, tetapi perlu dipanggil ulang saat `onResume` dan saat window kembali fokus agar system bars tidak menetap setelah keluar dari picker/setting Android.

## Tindakan lokal

- R8 full mode ditambahkan di `gradle.properties`.
- Debug build ikut `isMinifyEnabled=true` dan `isShrinkResources=true` supaya build yang tidak sengaja dipasang tidak membengkak dan keep-rule cepat ketahuan di CI.
- Source/line debug attributes tidak lagi disimpan oleh R8 rules.
- Radius token diperkecil: `SM 6`, `MD 9`, `LG 12`, `WIN 10`; icon mask turun dari 26% ke 21%.
- `Glass()` dan `Panel()` diberi liquid Aurora refraction: alpha lebih transparan, rim gradient, tint aksen sangat tipis, dan sheen tetap halus.
- Taskbar/dock dibuat lebih transparan (`alpha 0.76`) agar wallpaper/live wallpaper memengaruhi visual.
- Fullscreen diperkuat: theme fullscreen/cutout/transparent bars + `applyDesktopMode()` dipanggil ulang di `onResume` dan `onWindowFocusChanged`.

## Risiko dan batas jujur

- R8 tidak bisa mengontrol seluruh angka “ukuran aplikasi” yang ditampilkan Android Settings karena ART/data/cache ikut dihitung oleh OS.
- Debug ikut R8 membuat build debug lebih lambat dan stacktrace lokal kurang nyaman, tetapi lebih sesuai permintaan ukuran dan distribusi alpha.
- Liquid glass ini bukan blur backdrop native lintas-ROM; Compose menggambar refraction/tint transparan di atas wallpaper. Efeknya bergantung wallpaper dan kemampuan compositor ROM.
- Fullscreen masih bisa disela oleh gesture system/IME/panel Android; SukiOS akan menyembunyikan ulang saat fokus kembali.
