Status: **alpha, draft, belum untuk distribusi publik**. Build ini dibuat untuk uji perangkat nyata setelah Aurora v2 dan jendela freeform di `v0.4.0-alpha`.

## 1. Baru: live wallpaper sistem

- Setelan > Tampilan sekarang punya kartu **Live wallpaper sistem**.
- Tombol **Pakai** mengubah desktop SukiOS ke mode `system-live`: wallpaper Android/live wallpaper sistem digambar di belakang desktop.
- Tombol **Pilih live wallpaper** membuka picker live wallpaper bawaan Android (`ACTION_LIVE_WALLPAPER_CHOOSER`) dengan fallback ke picker wallpaper umum bila ROM tidak menyediakannya.
- Beranda SukiOS menyalakan `FLAG_SHOW_WALLPAPER`, theme memakai `windowShowWallpaper=true`, dan root Compose dibuat transparan saat mode ini aktif.
- SukiOS tetap menggambar veil Aurora transparan di atas wallpaper sistem supaya teks, taskbar, dan jendela tetap terbaca.

Batas jujur: SukiOS tidak menyertakan APK live wallpaper pihak ketiga. Pengguna tetap memilih/memasang live wallpaper lewat Android/ROM/Play Store.

## 6. Yang harus diuji di perangkat

1. Setelan > Tampilan > **Live wallpaper sistem** > **Pilih live wallpaper**: picker Android harus muncul.
2. Pilih live wallpaper apa pun, kembali ke SukiOS, lalu tekan **Pakai** bila belum aktif: wallpaper sistem harus terlihat di belakang desktop dengan veil gelap Aurora.
3. Ganti kembali ke salah satu preset Aurora: wallpaper bawaan SukiOS harus kembali menutup wallpaper sistem.
4. Pastikan teks desktop, taskbar, Start, Quick Panel, dan jendela tetap terbaca di atas live wallpaper terang/ramai.
5. Uji lagi Setelan > Jendela > Persiapan dan **Uji jendela**; perubahan wallpaper tidak boleh mengubah outcome freeform.
6. Buka aplikasi pihak ketiga sebagai jendela dan salin laporan Diagnostik setelah uji.

## 7. Batas yang diketahui

- Sebagian ROM tidak punya live wallpaper chooser standar; tombol akan fallback ke picker wallpaper umum.
- Live wallpaper bisa lebih boros baterai/GPU daripada wallpaper Aurora statis. Mode Go tetap mematikan gerak wallpaper Aurora, tetapi live wallpaper sistem dikendalikan oleh Android/ROM.
- Tanpa 4 secrets keystore rilis, APK draft ini tetap debug-signed dan tidak untuk distribusi publik.
