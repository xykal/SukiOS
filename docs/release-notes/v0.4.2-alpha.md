Status: **alpha, draft, belum untuk distribusi publik**. Fokus rilis ini: ukuran install/R8, fullscreen lebih keras, dan pass UI liquid glass yang lebih konsisten.

## 1. R8 / ukuran install

- Release tetap memakai R8 + shrink resources.
- Debug build sekarang juga memakai R8 + shrink resources agar APK debug yang tidak sengaja dipasang tidak membengkak seperti build tanpa shrink.
- `android.enableR8.fullMode=true` diaktifkan.
- Metadata `SourceFile`/`LineNumberTable` tidak lagi dipertahankan di APK minified.

Catatan jujur: Android Settings bisa menampilkan ukuran yang mencakup APK + data + cache + compiled oat ART. R8 mengurangi APK/dex/resources, tetapi tidak bisa menjamin angka Settings selalu kecil bila OS menghitung data/cache.

## 2. UI liquid glass + radius lebih rata

- Radius token dikurangi supaya UI tidak terlalu bulat:
  - `RADIUS_SM`: 8 -> 6
  - `RADIUS_MD`: 12 -> 9
  - `RADIUS_LG`: 16 -> 12
  - `RADIUS_WIN`: 14 -> 10
- Icon tile dan app icon mask lebih rata (26% -> 21% ukuran).
- `Glass()` sekarang punya liquid Aurora refraction: background lebih transparan, rim gradient, aksen tipis, dan sheen halus.
- `Panel()` ikut mendapat tint liquid tipis supaya kartu/panel lebih konsisten.
- Taskbar/dock dibuat lebih transparan (`alpha 0.76`) supaya wallpaper/live wallpaper terasa memengaruhi dock.

## 3. Fullscreen lebih tegas

- Theme memakai fullscreen, cutout short edges, transparent status/navigation bar.
- `SukiHomeActivity` menerapkan ulang fullscreen saat `onResume` dan saat window mendapat fokus kembali.
- Tujuannya: setelah keluar dari picker wallpaper/setting Android, SukiOS kembali ke desktop fullscreen otomatis.

## 6. Checklist uji perangkat

1. Pasang APK draft dan cek ukuran di Android Settings sebelum membuka banyak layar; bedakan App size, User data, dan Cache bila ROM menampilkan rinciannya.
2. Pastikan Beranda tetap fullscreen setelah kembali dari picker live wallpaper dan Settings Android.

4. Cek jendela internal: radius lebih rata, tidak terasa terlalu bulat, resize/snap tetap jalan.
